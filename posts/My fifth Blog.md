This week, we focused on developing the core interface and interaction flow for our anonymous chat website, *liminal*. Compared to previous weeks, this stage became much more technical, as we started translating our wireframes into an actual working website structure using HTML, CSS, and JavaScript. Our main focus this week was refining the room browsing experience, improving the overall user flow, and exploring a visual style that better reflects the concept of “liminal space.”

At the beginning of the development process, we reconsidered the navigation structure of the website. After reviewing our wireframes more carefully, we developed a clearer sequence: users first enter the Welcome page, then move to the Room Selection page, where they can either join an existing room, create a new room, or randomly enter a room. We felt this structure creates a more natural interaction process and better reflects how users explore social platforms.

One of the main improvements this week was the redesign of the Room Selection page. Instead of using a traditional vertical list layout, we developed a card-based interface inspired by social media platforms such as Xiaohongshu and Pinterest. Each room appears as a large rectangular card displaying a customised background and the room name created by users. We wanted the page to feel visually immersive rather than purely functional, allowing users to browse rooms more intuitively while also creating a stronger atmosphere for the platform.

For the room creation interaction, we used a floating “+” button as part of the Room Selection page. When users click it, two options appear: “Create” and “Random.” This keeps the page visually clean, while still allowing users to either create their own room or enter an existing room randomly.

In terms of visual design, we spent time exploring different atmospheric directions for the website background. Rather than using a flat or highly saturated colour scheme, we experimented with layered gradients and subtle lighting effects to create a softer starry-sky atmosphere. Our intention was not to create a realistic night-sky aesthetic, but instead to build a dreamlike and slightly unreal environment that feels calm, anonymous, and transitional.

Technically, this week involved connecting multiple pages together and implementing interactive behaviours through JavaScript. We developed page transitions, room selection interactions, floating menu behaviour, and temporary room data storage using local storage. Although the project is still in an early development stage, the overall visual identity and user experience are now much more consistent than before.

For next week, we plan to continue refining the chat room interface itself, improve responsive layouts for different screen sizes, and begin considering how room information and anonymous messages could connect with the database structure we previously planned through our ERD and DDD work.
